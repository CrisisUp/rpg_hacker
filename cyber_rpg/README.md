# 🌐 Cyber RPG: Invasão à OmniCorp

Um simulador de hacking tático via terminal, construído com foco em **Clean Code**, **Engenharia de Qualidade** e **Inteligência Artificial Pedagógica**.

## 🚀 Destaques Técnicos

- 🗺️ **Geração Procedural de Redes:** Topologias baseadas em Grafos.
- 🧹 **Clean Code & SRP:** Responsabilidades isoladas entre Managers e UI.
- 🛡️ **Tipagem Forte:** Uso de Dataclasses para contratos de dados seguros.
- 🎨 **Interface Premium:** Experiência visual rica com biblioteca Rich.
- 🤖 **Agente Ghost (IA):** Mentor in-game que explica a lógica hacker.
- 💾 **Persistência de Dados:** Sistema de Save/Load com Auto-save.

## 🧪 Engenharia de Qualidade (Testes)

Suíte de **16 testes unitários** validando todo o motor do jogo.
Rodar testes: \`python3 -m unittest discover tests -v\`

## 🕹️ Como Jogar

1. \`source venv/bin/activate\`
2. \`pip install -r requirements.txt\`
3. \`python src/main.py\`
