# 🌐 Cyber RPG: Invasão à OmniCorp

Um simulador de hacking tático via terminal, construído com foco em **Clean Code**, **Engenharia de Qualidade** e **Táticas Reais de Hacking**.

## 🚀 Destaques do Arsenal

### 🛠️ Táticas Modernas

- **Supply Chain Attack:** Infiltre-se em fornecedores para comprometer alvos corporativos via atualizações maliciosas.
- **Social Engineering:** Minijogo de Phishing dinâmico com personas realistas.
- **Zero-Day Crafting:** Colete fragmentos de vulnerabilidades para compilar exploits de uso único.
- **Modern Ransomware:** Escolha entre extorsão padrão ou dupla (vazamento de dados).

### 🤖 Inteligência Artificial Pedagógica

- **Agente Ghost:** IA mentora que toma o controle (comando "....") e explica os fundamentos táticos e de segurança por trás de cada ação.

## 🧪 Engenharia de Qualidade

O projeto conta com uma robusta suíte de testes unitários e de integração:

- **Testes Unitários:** Validação de jogadores, combate e estados.
- **Testes de Integração:** Mecânicas de cascata e compilação de Zero-Days.
- **Comando:** python3 -m unittest discover tests -v

## 🕹️ Início Rápido

1. source venv/bin/activate
2. pip install -r requirements.txt
3. python src/main.py
