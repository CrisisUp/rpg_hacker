# 📜 Game Design Document

## 🎯 Visão Geral

Simulador de hacking tático focado no equilíbrio entre recursos (RAM/Estabilidade) e risco (Rastreio).

## ⚙️ Mecânicas de Elite

- **RAM/Trace:** Gestão de hardware e tensão.
- **Agente Ghost:** IA Mentora (comando secreto \`....\`) para aprendizado tático.
- **Economia:** Coleta de loot e Mercado Negro de scripts.

## 🎭 Progressão

Fluxo de missões via JSON com objetivos narrativos específicos.
